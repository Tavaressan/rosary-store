# Rosary Store - Projeto 1º Semestre — Desenvolvimento de Software Multiplataforma

Bem-vindo(a) ao repositório do projeto desenvolvido durante o primeiro semestre do curso de **Desenvolvimento de Software Multiplataforma**.

## Sobre o Projeto

Este projeto foi criado com o objetivo de aplicar os conhecimentos adquiridos em HTML e CSS semântico. As atividades foram realizadas conforme as especificações dadas em aula, buscando sempre seguir as melhores práticas de desenvolvimento web.

## Tecnologias Utilizadas

- **HTML5**  
  Utilizado para estruturar o conteúdo da página de forma semântica.

- **CSS3**  
  Utilizado para estilização e layout do projeto, explorando seletores, propriedades e boas práticas de design responsivo.

## Objetivos

- Praticar a construção de páginas web semânticas.
- Utilizar corretamente as tags HTML5.
- Aplicar estilos CSS para aprimorar a aparência e usabilidade do site.
- Seguir as especificações propostas pelo(a) professor(a).
